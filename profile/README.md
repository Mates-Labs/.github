## Qué hacemos

Creamos soluciones web a medida para acompañar las necesidades de cada negocio:

- Sitios web y aplicaciones modernas.
- Herramientas digitales para operaciones y gestión.
- Integraciones y automatizaciones.
- Bases técnicas preparadas para crecer y mantenerse.

Combinamos diseño y desarrollo con prácticas de ingeniería orientadas a entregar software claro, confiable y fácil de evolucionar.

## Cómo trabajamos

- **Calidad desde el desarrollo:** validaciones de código, formato, tipos, pruebas y build.
- **CI/CD automatizado:** verificaciones en cada pull request y en los cambios a `main`.
- **Seguridad integrada:** permisos mínimos y análisis automatizado de secretos.
- **Soluciones a medida:** elegimos las tecnologías según el producto y sus objetivos.
